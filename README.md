# ALL IN ARCADE

A conference-booth arcade, built live by [Fabric](https://github.com/farpointhq) agents
level by level while attendees play. 12 playable levels across 9 genres — platformers,
racers, puzzles, a shot 'em up, a dungeon crawler, a zombie apocalypse runner and more —
each dreamed up by a booth visitor, generated by an agent, and tuned on the spot.

## Play it

```bash
python3 serve.py --port 8181
# open http://localhost:8181/
```

Any static file server works for browsing, but the booth server also exposes
`/api/levels` and `/api/submit` (the "Contribute an idea" kiosk), so use `serve.py`.

## What's in the box

- **Canvas engine** (`src/core.js`): 960x540 stage, sprite bakery, seasonal tints.
- **Genre modules** (`src/genres/`): one self-contained module per genre; levels are
  plain JSON in `levels/<id>/level.json` and get loaded through
  `levels/manifest.json`.
- **Title screen carousel**: real gameplay screenshots of every level, snapshotted
  at boot and cached in `localStorage`, sliding behind the menus.
- **Cross-level lives**: a heart bank that carries across levels (spend on deaths,
  gain from pickups, capped at 9, never dead-ends the booth).
- **Sound options**: music and SFX toggles + master volume, persisted.
- **Seasons**: a global season switcher that mutates level mechanics.
- **Kiosk mode**: attendees pitch a level idea; a Fabric agent builds it during the show.

## Music

Real loops are used from OpenGameArt (CC0 / CC-BY 3.0). Author + license notes are
in [`assets/audio/CREDITS.md`](assets/audio/CREDITS.md). Everything else (SFX, and any
genre without a track) is synthesized at runtime with WebAudio — no binaries needed.

## Structure

```
levels/<id>/level.json   # level data (title, authors, style, gameplay data)
src/                     # engine, app orchestration, per-genre gameplay, audio
assets/audio/            # real music loops + CREDITS.md
```
